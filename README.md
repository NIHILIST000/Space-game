# Space game

Космический шутер с пиксельной графикой, написанный на Python. Управляйте звездолетом, уничтожайте вражеские корабли и астероиды, используйте щиты для защиты.

## Управление

- **Стрелки ← → ↑ ↓** - движение корабля
- **ПРОБЕЛ** - стрельба
- **S** - активировать щит (ограниченное время)
- **ESC** - выход в меню

## Система очков

- Вражеский корабль: 10 очков
- Астероид: 5 очков

## Особенности

- Пиксельная графика с детализированными спрайтами
- Система щитов для защиты
- Случайная генерация врагов и астероидов
- Фоновая музыка с регулировкой громкости
- Полное руководство по игре
- Подсчет очков
